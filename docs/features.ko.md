# 기능

[English](features.md)

- [o] S1 — P1: 이 sidecar를 자기 repository로 build, test, release한다. 2026-10-02에 soksak core repository(그곳의 checklist 항목 R1-5-2)에서 옮겼으며, 이전 변경 이력은 core에 있다. macOS arm64에서 `make test`, `make build`, `make release`가 통과한다.
- [o] S2 — P1: 같은 영속 연결에서 closed 알림을 받은 표면을 다시 연다. 2026-10-02 core window check `library windows create and open projects in place`에서 발견: 터미널을 보인 창을 닫은 프로젝트를 새 창에서 보일 수 없었다. 터미널 open이 `stale attachment`로 거부되어 호스트가 오지 않는 터미널 그림을 기다렸다. closed 알림은 registry 항목을 지웠지만 표면의 송신기와 부착 판을 연결에 남겨, 다음 open이 항목이 없는 registry와 옛 판을 비교했다. 2026-10-02 완료: 닫기가 성공하면 이 둘도 지운다. Red: `a_surface_reopened_after_its_closed_notice_is_not_a_stale_attachment`가 `stale attachment` 응답 두 개를 받았다. Green: 그 test와 `make test`가 macOS arm64에서 통과한다.
- [o] S3 — P1: soksak core 0.0.2용 version 0.0.2를 release한다. 2026-10-02 완료: `vt-core`와 `vt-alacritty`가 0.0.2를 선언하며 S2를 담는다. macOS arm64에서 `make test`가 통과한다(test 274개).
- [o] S4 — P1: 자기 줄을 끝내는 프롬프트 위의 출력을 터미널 크기 변경 때 유지한다. 2026-10-02 core window check `a resize redraws a wrapped zsh input line without rows of the previous width`(core G1.4-46)에서 발견: 69자 zsh 프롬프트가 23열에서 세 행을 채우고 zsh는 입력을 다음 줄에 썼다. 46열로 넓힌 뒤 zsh는 네 행 올라갔지만, engine은 커서가 있는 논리적 행의 첫 행부터 영역을 재어 커서를 프롬프트 시작보다 세 행 아래에 두었으므로 다시 그리기가 프롬프트 위의 출력 행을 덮어썼다. 2026-10-02 완료: engine은 `133;A`(그리고 프롬프트 상태의 ED 2)에서 프롬프트 시작을 기록하고, 기록이 행을 버려도 맞게 유지하며, `redraw=1`이면 그 행부터 지운다. bash 통합은 `redraw=last`를 보내 커서가 있는 논리적 행의 영역을 유지한다. 진단 build는 표면의 engine 입력을 기록한다(`SOKSAK_VT_TRACE_DIR`). 실패한 window check의 trace가 원인을 찾았다. Red: `a_widening_resize_counts_the_rows_of_a_prompt_that_ended_at_the_margin`, `a_resize_clears_every_row_from_the_prompt_start_when_the_prompt_ends_its_own_line`, `a_prompt_redrawn_after_a_screen_clear_starts_at_the_top_row`가 커서를 한두 행 높게 두었다. Green: 이 test들과 `cargo test`가 통과하고, core의 zsh와 bash redraw window check가 두 host에서 두 번 통과한다.
- [o] S5 — P2: Rust 코드에 clippy 경고가 없게 한다. 2026-10-02 S4를 검증하다 발견: 이 repository의 어떤 검사도 clippy를 실행하지 않아 `cargo clippy`가 `vt-core`에서만 경고 55개를 보고했다. 그중 하나는 `encode_paste`의 doc 주석이 `encode_mouse` 위에 있음을 보였다. 2026-10-02 완료: `make test`가 `cargo clippy --workspace --all-targets --features diagnostics -- -D warnings`를 실행한다. 인수가 일곱 개를 넘는 함수는 `SurfacePorts`, `ServeOptions`, `PersistentOwner`, `ImageConfiguration`을 받고, theme 명령은 theme을 box에 담으며, `platform/platform.rs`는 `platform/mod.rs`로 합쳤다. PTY test는 await를 넘어 async 잠금을 잡고, doc 주석은 `encode_paste`로 돌아갔다. `make test`가 macOS arm64에서 통과한다.
